# 钱迹账单清理与导入

## 类型

无状态型。

1. Skill 只写入用户本次要求的清理结果和统计表副本，不写入调用结束后必须保留的内部状态。
2. 本次调用不读取以往调用生成的账单、结果或执行记录。
3. 单次读取量只取决于本次输入文件和目标统计表，不随使用次数增长。

## 两种任务

- **只清理**：扫描钱迹账单，确认日期范围，输出独立的 `<原文件名>_清理版.xlsx`。
- **清理并导入**：除清理版外，再把同一批记录导入用户提供的财务统计表副本中，目标页默认为「5.每日收入支出明细表」。

输入支持 UTF-8 CSV 和 XLSX。其他格式先停止并说明，不静默改变读取方式。

## 固定清理规则

按以下顺序执行：

1. 只读扫描输入文件的字段、记录数、日期范围、「账单标记」数量和「类型」分布。
2. 报告排除标记行及非收入／支出记录后的可保留日期范围，然后暂停并询问用户最终保留的日期范围。问题中给出格式示例：`2026-07-01 至 2026-07-31（包含起止日期）`。收到明确起止日期前不得继续，不自行采用全部日期或上次范围。
3. 删除「账单标记」去除首尾空白后仍有内容的整行。
4. 「类型」去除首尾空白后只保留「收入」和「支出」。
5. 只保留用户指定日期范围内的记录，包含起止日期。日期无效、起始日期晚于结束日期或范围内没有记录时停止。
6. 只保留「时间」「分类」「二级分类」「类型」「金额」「备注」「标签」。
7. 将「标签」按 `#` 分成「标签 1」「标签 2」。没有 `#` 时原内容进入「标签 1」；超过 1 个 `#` 时停止，避免丢失内容。
8. 「时间」转换为真实日期值，显示为 `yyyy-mm-dd`；金额转换为数值。
9. 按日期升序排列；同一天保持输入文件中的相对顺序。
10. 输出列固定为「时间」「分类」「二级分类」「类型」「金额」「备注」「标签 1」「标签 2」。

## 目标统计表检查

只有用户要求导入时才执行：

1. 先以只读模式检查目标工作簿，不把测试模板或用户私人路径写入 Skill 文件。
2. 目标工作表必须存在，前 8 列依次匹配「日期」「一级分类」「二级分类」「类型」「金额」「备注」「支出类型」「支出必要性」；已知模板中的「一级分类ｼｭｯﾋﾟ」也视为合法表头。
3. 固定映射为：
   - 时间 → 日期
   - 分类 → 一级分类
   - 二级分类 → 二级分类
   - 类型 → 类型
   - 金额 → 金额
   - 备注 → 备注
   - 标签 1 → 支出类型
   - 标签 2 → 支出必要性
4. 自动识别目标页顶部连续数据区与后部保留数据区，只向两者之间的空白区写入；容量不足时停止。
5. 默认追加。如果目标表已有记录与本次导入日期重叠，默认停止并报告重叠行数和日期范围，只询问一个会改变动作的问题：
   - `replace`：清空目标表中与本批记录日期相同的旧行，再追加本批记录；
   - `append`：保留旧行并继续追加，可能形成重复记录。
6. 未获得用户明确选择时不得替用户决定 `replace` 或 `append`。日期重叠检查不能当作逐笔去重；相同日期、金额和备注仍可能是两笔真实交易。

## 文件安全

- 原钱迹账单始终只读。
- 原财务统计表始终只读；导入结果写入同目录下带时间戳的独立副本，除非用户另行指定输出路径。
- 不支持原地覆盖统计表。输出同名文件已存在时停止或生成新的时间戳文件，不静默覆盖。
- 导入时保留工作簿中的其他工作表、样式、数据验证、保护设置、图表、切片器和数据透视表文件；将数据透视缓存标记为打开时刷新，并要求 Excel 完整重算。
- 任一步失败时不得留下只有部分导入数据的统计表副本。

## 执行

使用仅依赖 Python 3 标准库的 [scripts/qianji_bill.py](scripts/qianji_bill.py)。所有包含空格的路径都使用 shell 引号。

先扫描钱迹账单：

```bash
python3 scripts/qianji_bill.py inspect --input '<输入路径>'
```

只读检查统计表：

```bash
python3 scripts/qianji_bill.py inspect-target \
  --target '<统计表路径>' \
  --sheet '5.每日收入支出明细表'
```

收到用户日期范围后，只清理：

```bash
python3 scripts/qianji_bill.py clean \
  --input '<输入路径>' \
  --output '<清理版路径>' \
  --start-date <YYYY-MM-DD> \
  --end-date <YYYY-MM-DD>
```

清理并导入：

```bash
python3 scripts/qianji_bill.py clean-import \
  --input '<输入路径>' \
  --clean-output '<清理版路径>' \
  --target '<原统计表路径>' \
  --target-output '<带时间戳的统计表副本路径>' \
  --start-date <YYYY-MM-DD> \
  --end-date <YYYY-MM-DD> \
  --sheet '5.每日收入支出明细表' \
  --overlap-policy stop
```

只有用户明确处理重叠方式后，才将最后一个参数改为 `replace` 或 `append`。

## 交付核对

脚本会回读输出并输出 JSON 统计。交付前核对：

- `sourceRows = removedMarkedRows + removedOtherTypeRows + removedOutsideDateRows + outputRows`；
- 清理版表头与固定 8 列一致，类型只含收入／支出，日期非降序，日期与金额均为数值；
- 导入行数与清理版行数一致；
- `firstWrittenRow` 至 `lastWrittenRow` 位于目标可写区；
- 统计表副本可以作为 ZIP／XLSX 完整回读，目标页导入后行数符合预期；
- 原始账单和原统计表的修改时间、大小与内容未被改动；
- 向用户明确给出清理版和已导入统计表副本的路径，以及本次采用的重叠策略。

# 钱迹账单清理

## 类型

无状态型。

1. Skill 本身不保留跨调用状态；生成的 XLSX 是本次用户交付文件，不是后续调用必须读取的内部记录。
2. 本次调用不读取以往调用留下的账单或清理结果。
3. 单次读取量只取决于本次输入文件，不随使用次数增长。

## 输入与输出

- 输入可以是对话附件的本地路径，或用户明确提供的文件路径。
- 确定性脚本支持 UTF-8 CSV 和 XLSX。其他表格格式使用当前可用的电子表格工具读取，再执行同一组规则。
- 用户指定输出目录时写入该目录；未指定时才询问输出目录。
- 默认输出名为 `<原文件名>_清理版.xlsx`。不得覆盖源文件；同名输出已存在时，生成带时间戳的新文件名，除非用户明确授权覆盖。

## 固定清理规则

按以下顺序执行，不改变字段名称所表达的业务含义：

1. 只读扫描输入文件的字段、记录数、日期范围、「账单标记」数量和「类型」分布，不生成输出文件。
2. 报告排除标记行及非收入／支出记录后的可保留日期范围，然后暂停并询问用户最终保留的日期范围。问题中必须给出格式示例：`2026-07-01 至 2026-07-31（包含起止日期）`。收到明确的起止日期前不得继续清理；不得自行采用全部日期或上次范围。
3. 找到「账单标记」列中去除首尾空白后仍有内容的记录，删除整行。
4. 自动识别「类型」列去除首尾空白后的值，只保留「收入」和「支出」，其他类型删除整行。
5. 只保留用户指定日期范围内的记录，起止日期均包含在内。日期无效、起始日期晚于结束日期，或范围内没有可保留记录时停止并报告。
6. 只保留「时间」「分类」「二级分类」「类型」「金额」「备注」「标签」。
7. 将「标签」按 `#` 分成「标签 1」「标签 2」两列。没有 `#` 时，原内容进入「标签 1」，「标签 2」留空；出现超过 1 个 `#` 时停止并报告，避免静默丢失标签。
8. 「时间」只保留日期，写入真实日期值，显示格式为 `yyyy-mm-dd`。
9. 按「时间」升序排列；同一天的记录保持输入文件中的相对顺序。
10. 输出列固定为「时间」「分类」「二级分类」「类型」「金额」「备注」「标签 1」「标签 2」。

## 执行

使用 [scripts/clean_qianji_bill.mjs](scripts/clean_qianji_bill.mjs) 完成元数据扫描和确定性转换。运行前按当前电子表格运行时要求准备 `@oai/artifact-tool`，并在临时工作目录执行。

先扫描元数据：

```text
node clean_qianji_bill.mjs --mode inspect --input <输入路径>
```

向用户报告扫描结果并询问日期范围。收到回复后再清理：

```text
node clean_qianji_bill.mjs --mode clean --input <输入路径> --output <输出路径> --start-date <YYYY-MM-DD> --end-date <YYYY-MM-DD> [--preview <预览 PNG 路径>]
```

脚本输出 JSON 统计。交付前核对：

- `sourceRows = removedMarkedRows + removedOtherTypeRows + removedOutsideDateRows + outputRows`
- 输出表头与固定的 8 列完全一致
- 「类型」列只包含「收入」和「支出」
- 所有记录均在用户指定的日期范围内，且包含起止日期
- 所有日期可解析，且日期非降序
- 「账单标记」列和其他已删除列不存在
- 标签内容没有因分列丢失
- 金额为数值，日期为真实日期值
- 至少完成一次工作表预览，确认表头、日期、金额与备注可读

原文件只读，不另存中间数据到用户目录。
